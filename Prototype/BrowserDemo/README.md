# Milestone 1 Browser Prototype

This standalone prototype covers the first playable loop described in the game design document:

- Rusthollow combat arena with movement, mouse aiming, and firing
- Tactical Focus slow-time ability and Bio-Boost
- Five Core Abilities with skill-point upgrades
- XP, levels, and level-gated implant slots
- Three Bounty Terminal objectives: clear raiders, recover fuel cells, and survive an ambush

Run from this directory with `python3 -m http.server 8000`, then open `http://localhost:8000`.

Controls: WASD or arrow keys to move, mouse to aim, left mouse button to fire, Shift or Space for Tactical Focus, and E for Bio-Boost.
